# PLP Python Week 4 - Decision Making

This assignment practices decision-making in Python using `if`, `elif`, `else`, logical operators, input validation, and nested conditionals.

## Files

### grade_classifier.py
Asks the user for a score from 0 to 100, validates the score, and assigns a grade from A to F.

### eligibility_checker.py
Checks whether a person is eligible to join a coding club based on their age and parental consent.

### atm_menu.py
Simulates a simple ATM by checking a PIN and allowing a withdrawal when sufficient funds are available.

## When is `elif` better than several separate `if` statements?

`elif` is better when only one condition should be selected from several possible choices. It checks the conditions in order and stops once one condition is true. This makes the program clearer and prevents multiple conditions from running when they should be mutually exclusive.
